## Art, audio and fonts

By [Kenney](https://kenney.nl), released under CC0 (public domain). Each
pack keeps its `License.txt` next to the files.

| Pack | Used for |
|---|---|
| Racing Kit, Racing Kit v2 | The cars, the start gantry and lights, the pit garages, grandstands, barriers, tents and the Proving Ground's road |
| Car Kit | Team cars, the safety car, cones and debris |
| City Kit (Commercial, Roads, Suburban) | Street circuits, towns and the harbour front |
| Nature Kit | Trees, rocks, hills and the countryside |
| Watercraft Pack | Boats in the harbours and on the lakes |
| Mini Arena | Fences and stands |
| Skyboxes | Skies |
| Flag Pack | Drivers' nationalities |
| Input Prompts | Controller and keyboard button glyphs |
| UI Pack - Adventure | Menus and panels |
| Kenney Fonts | All text |
| Music Loops | Music: Time Driving, Flowing Rocks and Mission Plausible |
| Impact Sounds, Interface Sounds | Contact, menus and the radio |

The engines, tyres, kerbs, gravel, wind, rain spray, crowds and the pit
crew's air guns are synthesized by the game's own code (`game/audio/`,
`tools/bake_engine.gd`); the baked samples are in `assets/audio/`. Liveries,
the track surface, kerbs, run-off and barriers are made in code.
